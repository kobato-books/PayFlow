# PayFlow

毎月の支払い準備と資金移動を管理するAppSheetアプリ。

口座振替や振込の前に、

- 今月いくら必要か
- 請求額を確認したか
- 各口座にいくら必要か
- 現在残高はいくらか
- いくら移動すればよいか

を確認できるようにする。

## 目的

これまで紙やExcelで行っていた
「請求額の確認 → 必要額の集計 → 口座残高確認 → 資金移動」
をAppSheetで管理する。

家計簿ではなく、**支払い前の準備に特化したアプリ**。
