# 支払い準備・資金移動管理

毎月の口座振替・振込に備えて、必要金額と口座残高を確認し、
「どの口座に、いくら準備すればよいか」を把握するためのAppSheetアプリ。

Googleスプレッドシートをデータ基盤として使用する。

## 目的

これまでExcelや紙で行っていた、

- 今月の請求額の確認
- 請求書・明細を確認したかのチェック
- 口座ごとの必要金額の集計
- 現在残高の確認
- 不足金額の把握
- 必要な資金移動

をAppSheetで管理する。

家計簿そのものを作ることが目的ではない。
MoneyForwardなどは資産・家計全体の把握に引き続き利用し、
このアプリは「支払い前の準備」に特化する。


## 基本的な考え方

### 支払いの確認

毎月発生する支払いを一覧化する。

固定額は支払先マスターから初期値を利用し、
カードなどの変動額は当月の請求額を入力する。

各支払いについて、

- 金額確認済み
- 今月は支払いなし

を記録できるようにする。

最終的には、

「確認済み 12 / 15」
「未確認 3件」

のように、未確認件数をすぐ確認できる画面を作る。


### 給料日前と給与入金後

給与日は28日。

支払い準備では単純な1か月単位だけでなく、
「どの給与から準備する支払いか」を意識する。

例：

- 26日・27日の支払い → 給料日前に準備
- 28日の給与入金後に準備する支払い → 給与入金後

10月2日の引落でも、
9月28日の給与から準備するものは「給与入金後」の準備対象となる。

そのため、

「支払月」
と
「準備するタイミング」

は別の概念として管理する。


## データ構成

AppSheetでは以下の5テーブルを使用。

### 1. 月次支払い

実際の各月の支払いデータ。

主な項目：

- 月次支払ID
- 対象年月
- 支払先ID
- 支払先名控え
- 実際の引落日
- 実際の口座ID
- 会計区分
- 今月の金額
- 確認済み
- 今月なし
- 準備ID
- 支払方法
- 支払回次
- 引落・出金済日時
- 生成識別子
- 備考

支払先マスターの情報を基本とするが、
当月だけ金額・日付・口座などを変更できるようにする。


### 2. 支払先マスター

通常の支払い条件を管理。

例：

- 住宅ローン
- クレジットカード
- 水道
- 保険
- 学費
- 仕送り
- 積立
- 小遣い

主な項目：

- 支払先ID
- 支払先名
- 通常口座ID
- 通常引落日
- 月末扱い
- 通常金額
- 金額区分
- 支払パターン
- 支払方法
- 会計区分
- 通常準備区分
- 使用状態


### 3. 口座マスター

支払い・資金移動に使用する口座を管理。

主な項目：

- 口座ID
- 口座表示名
- 銀行名
- 名義
- 会計区分
- 役割・備考
- 使用状態

名義と会計区分は別々に管理する。

現在は、

- ショウタロウ名義 → 主に家計
- 友紀子名義 → 主に友紀子個人

としている。

口座番号・ログインID・パスワードなどの
機密情報は保存しない。


### 4. 口座残高

口座残高の確認履歴。

残高を上書きするのではなく、
確認するたびに履歴として追加する。

主な項目：

- 残高ID
- 準備ID
- 口座ID
- 会計区分控え
- 確認日時
- 現在残高
- 備考


### 5. 準備管理

「いつの支払い準備か」をまとめる単位。

主な項目：

- 準備ID
- 準備対象月
- 準備区分
- 会計区分
- 一覧作成済み
- 備考


## AppSheet設定状況

### テーブル登録

以下5テーブルをAppSheetへ登録済み。

- 月次支払い
- 口座マスター
- 口座残高
- 支払先マスター
- 準備管理

設計メモなどの管理用シートはAppSheetには登録していない。


### 月次支払い

設定済み：

- 月次支払ID
  - Text
  - Key
  - Initial value: `UNIQUEID()`

- 対象年月
  - Date

- 支払先ID
  - Ref
  - 参照先：支払先マスター

- 実際の引落日
  - Date

- 実際の口座ID
  - Ref
  - 参照先：口座マスター

- 今月の金額
  - Price

- 確認済み
  - Yes/No

- 今月なし
  - Yes/No

- 準備ID
  - Ref
  - 参照先：準備管理

- 引落・出金済日時
  - DateTime


### 支払先マスター

設定済み：

- 支払先ID
  - Text
  - Key

- 通常口座ID
  - Ref
  - 参照先：口座マスター

- 通常引落日
  - Number

- 月末扱い
  - Yes/No

- 通常金額
  - Price

- 金額区分
  - Enum

- 支払パターン
  - Enum

- 支払方法
  - Enum

- 会計区分
  - Enum

- 通常準備区分
  - Enum

- 使用状態
  - Enum

Ref設定により、
`Related 月次支払いs`
などの逆参照列もAppSheetによって自動生成されている。


### 口座マスター

設定済み：

- 口座ID
  - Text
  - Key

- 口座表示名
  - Text
  - Label

- 銀行名
  - Text

- 名義
  - Text

- 会計区分
  - Enum

- 役割・備考
  - LongText

- 使用状態
  - Enum

口座表示名をLabelにしているため、
Refでは `ACC008` のような内部IDではなく、
「ドコモ銀行（M）」などの表示名を利用できる。
